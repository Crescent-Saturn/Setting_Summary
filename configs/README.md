# 配置文件

这些文件仅供参考，不代表经过验证的默认配置。安装前请检查依赖、应用版本和本地路径。配置文件中不得包含凭据、私钥、激活码或真实内部主机名。

| 路径 | 用途 | 状态 |
|---|---|---|
| [`vim/.vimrc`](vim/.vimrc) | Vim 偏好和插件声明 | 待复核；依赖第三方插件 |
| [`yt-dlp/config`](yt-dlp/config) | yt-dlp 输出、格式和字幕选项 | 请按安装版本核对；参见[软件目录](../docs/topics/software-catalog.md) |
| [`sublime/`](sublime/README.md) | 历史 Sublime Text 设置和快捷键 | 旧配置；依赖可能缺失 |
| [`ssh/config.example`](ssh/config.example) | 已清理敏感信息的 OpenSSH 配置示例 | 仅供参考；使用前替换占位内容 |
