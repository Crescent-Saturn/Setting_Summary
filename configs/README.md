# Configurations

These files are starting points, not verified defaults. Review dependencies, application versions, and local paths before installing them. Configurations must not contain credentials, private keys, activation codes, or actual internal hostnames.

| Path | Purpose | Status |
|---|---|---|
| [`vim/.vimrc`](vim/.vimrc) | Vim preferences and plugin declarations | Needs review; plugins are external |
| [`yt-dlp/config`](yt-dlp/config) | yt-dlp output, format, and subtitle options | Needs review against installed yt-dlp version; see [software catalog](../docs/topics/software-catalog.md) |
| [`sublime/`](sublime/README.md) | Historical Sublime Text settings and key bindings | Legacy; dependencies may be missing |
| [`ssh/config.example`](ssh/config.example) | Sanitized OpenSSH client example | Example only; replace placeholders |
