## 旧版 Windows 10 笔记

旧版 README 包含 Windows 10 隐私、组策略、服务和电源设置调整。这些内容尚未针对当前 Windows 版本重新验证，因此不再作为操作清单提供。尤其不要依据旧笔记关闭 Microsoft Defender 或其他安全保护、禁用系统服务或更改更新策略。

更改策略、服务或隐私设置前，请查阅对应 Windows 版本的 Microsoft 文档，并评估对更新、安全和设备管理的影响。优先使用受支持的“设置”界面和可撤销的用户级更改。

旧笔记还包含 DISM 和 SFC 修复命令。仅在诊断实际系统问题时参考 Microsoft 当前的修复指南；不要将其作为日常优化步骤。
