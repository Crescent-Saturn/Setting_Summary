## 桌面偏好

旧笔记提到 GNOME Shell 扩展、文件预览工具和 GRUB 主题。这些都属于可选偏好，并非必需步骤。请先确认兼容性，仅从可信来源安装扩展和主题；不要运行未经审查的安装脚本。

## 双系统时钟

旧笔记曾建议将硬件时钟设为本地时间，以同步 Windows 和 Linux。这可能影响时间处理，因此不作为默认建议。更改前请优先查阅发行版当前支持的方案，并验证两个系统的时区和时钟行为。
